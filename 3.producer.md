## Transaction 
- the idea is same as `transaction` in `database acid` 
- Use case: we need to publish to two topic at a time, but if the first one sending successfully, and consumer success, then in the second message sending, kafka crash and we never sending this to that topic
  

```
producer.send('topic-1') 
producer.send('topic-2') <-- kafka crash then never publish this message 
```
